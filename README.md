## 📖 About

AI Career Hub Backend is a REST API that provides career-related services such as jobs, internships, AI tools, roadmaps, projects, contact messages, and user authentication. The project was developed during the **Decode Labs Full Stack Development Internship**.

---

# ✨ Features

- 💼 Jobs API
- 🎓 Internships API
- 🤖 AI Tools API
- 🗺️ Roadmaps API
- 📂 Projects API
- 📩 Contact API
- 👤 User Registration
- 🔐 User Login
- ✅ Input Validation
- 🌐 RESTful API

# 🚀 Installation

### Install Dependencies

```
npm install
```

### Run the Server

```
npm run dev
```

Server runs on

```
http://localhost:5000
```
